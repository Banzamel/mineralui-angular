Breakpoints resolve upward. For example <m-grid-item [sm]="12" [lg]="6" /> means sm 12, md 12, lg 6, xl 6 and xxl 6.

If you skip a smaller breakpoint, the row calculates it automatically from the visible columns. That is why a remaining column expands to fill the row when a neighbour becomes hidden with hiddenUpTo.

xxl is the input name for the shared system breakpoint 2xl at 1536.

The row reads its direct m-grid-item children, also those rendered with @for or @if, and resolves their spans together. Rows nest: an m-grid inside an item is resolved on its own.

Plain elements work as equal columns too. They are counted after rendering, so a server-rendered page shows them in one column until the browser takes over — use m-grid-item for layouts that must be right in the prerendered HTML.

Supported values: stretch (default), start, center, end, baseline.

Rows always stretch to the available width, columns split evenly by default, and most responsive layouts only need sm, md and lg.

The sidebar slot takes m-sidebar or any element marked mAppShellSidebar. Put a <main> inside m-body for the page's main landmark.
