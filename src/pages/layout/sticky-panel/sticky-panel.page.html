Detail pages often pair a long, scrollable article with a short side rail — a lessons timeline, a notifications stream, an activity log, a notes pane. The rail should sit pinned to the viewport while the article scrolls, fill the available vertical space, scroll its own overflow, and stay tidy on small viewports. m-sticky-panel is the wrapper that does exactly that, so you stop hand-rolling position: sticky + calc(100vh - …) + scrollbar-hiding CSS + drag-to-scroll listeners on every page.

Drop the panel into any flex or grid item that lets it stretch — it sticks within the stretched parent and scrolls internally when its children overflow.

The host element is the scrollable panel, so a template reference (#panel + viewChild) gives you scrollTo, observers or focus(). Turn dragging off with [dragScroll]="false" when the panel holds text people select. MineralUI for React calls this prop draggable — in Angular that name would clash with the global HTML attribute.

The scrollbar is hidden by default (scrollbar-width: none, -ms-overflow-style: none, ::-webkit-scrollbar); set [hideScrollbar]="false" to bring the native track back.

The panel is focusable (tabindex="0"), so keyboard users can scroll it with arrows and Page Up / Page Down. Give it a label to expose it as a named region landmark.

Height is computed from the viewport, not from the content: calc(100vh - top - bottomGap). Adjust top to clear a fixed app header (e.g. [top]="88" for a 72 px header plus 16 px breathing room) and bottomGap to leave space for a footer. On viewports shorter than top + bottomGap the panel relies on min-height: 0.
