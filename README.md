# MineralUI for Angular

Modern Angular UI framework with a sharp admin aesthetic, theming system, and production-ready components.

- status: in development, not published yet
- npm: `@banzamel/mineralui-angular`
- React edition: `@banzamel/mineralui` (`https://github.com/Banzamel/mineralui-react`)
- homepage: `https://mineralui.io`

## Basic vs Pro

This repository will host the public Basic edition of MineralUI for Angular.
Premium components, templates, package access, and installation tooling are distributed separately in MineralUI Pro.
