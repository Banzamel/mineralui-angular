Using Signal Forms? The same fields bind with [formField] — see Signal Forms.

  • Phone, card number, CVC, NIP / PESEL / REGON, postal code — digits (600700800), the shown text comes from (formattedChange).
  • IBAN — the full IBAN without spaces (PL61109010140000071219812874).
  • Number, currency, slider — number (null when empty), so Validators.min / max work directly.
  • Date — a Date once complete; a half-typed date is null and still invalid (mDate).
  • File — readonly File[]; the rest — string.
