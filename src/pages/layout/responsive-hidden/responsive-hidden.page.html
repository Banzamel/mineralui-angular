hiddenUpTo="sm" hides on sm and smaller screens; hiddenUpTo="md" on md, sm and smaller. lg, xl and 2xl (up to 1536) follow the same pattern.

hiddenAbove="lg" hides strictly above lg — the complement of hiddenUpTo="lg". Pair the two on sibling grid items with the same breakpoint to swap a desktop layout for a compact one without injectMaxWidth.

MineralUI for React calls the first prop hidden. In Angular a hidden input would clash with the native attribute (ADR 0004): use the native hidden to hide always, hiddenUpTo for the breakpoint rule.

The inputs are CSS-driven: they set data-m-hidden / data-m-hidden-above, and styles.css hides the element with max-width / min-width media queries. No matchMedia, no change detection on resize, correct in server-rendered HTML.

For form fields or overlays, prefer hiding a parent container instead of the control itself.

In m-grid-item the matching column input is xxl for the 2xl breakpoint. Breakpoints: sm 640, md 768, lg 1024, xl 1280, 2xl 1536.
